# Stepwise Console Implementation Plan

> Use superpowers:executing-plans; retain the frontend-design visual system.

**Goal:** 用户点击按钮后启动浏览器，在同一页面逐条发送指令、持续录制并保存完整流程；可删除保存的流程。

## Decisions
- 新增显式浏览器启动接口；应用启动、读取状态和订阅画面均不启动浏览器。发送指令和回放前必须先点击启动。
- 新操作台为多轮对话；每轮只完成本条指令并等待，不重新导航起始页。每轮重新观察当前页面，使用有限历史理解上下文。
- 同一会话累积成功动作和参数草稿，保留跨轮流程；刷新页面恢复对话。新会话清空未保存录制，但不关闭或重置浏览器。
- 删除默认仅删除所选版本，可明确选择删除全部版本；保留凭据、运行历史与下载文件，运行期间禁止删除。
- 保留现有 explore 接口供兼容，Web UI 改为 chat；原有测试显式启动浏览器。

## Tasks
1. 先写启动门禁、删除、跨轮录制、无动作回复的失败测试。
2. 实现会话状态与持久化，扩展 Agent 的 continue 模式而不改变原有单次执行行为。
3. 接入启动、会话、删除 API，防止并发启动和运行期间重置/删除。
4. 将左栏改为对话记录与输入框，增加启动按钮、流程删除对话框、保存本次完整录制。
5. 单元/API/构建、脚本模型多轮真实浏览器验证、界面截图、独立审阅、推送。

## Scope notes
- 本轮不自动重试 Flyme 验证码，也不将真实网站凭据加入测试数据。
- 启动门禁不关闭用户已打开的 Chrome 会话；重启服务后仍需显式点击连接/启动。
